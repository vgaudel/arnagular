Démonstration du Control Flow Angular

1. @if

@if (isLoggedIn){

Vous êtes connecté.

}@else {

Vous n'êtes pas connecté.

} @if(isLoggedIn){ @if (userRole === "admin"){

Administrateur

} @else if (userRole === "editor") {

Éditeur

}@else {

Invité

} }

2. @for avec track et @empty

Liste de fruits :

    @for (fruitItem of fruits; track fruitItem){
  • {{fruitItem}}
    • }

Liste des utilisateurs (avec index) :

    @for (userItem of users; track userItem.id){
  • {{$index + 1}}. {{userItem.name}}({{userItem.id}})
    • }

Liste vide (@empty)

    @for (emptyItem of emptyList ; track emptyItem){
  • {{emptyItem}}
    • } @empty {
  • Aucun élément à afficher.
    • }

3. @switch / @case / @default

@switch (status) { @case ('loading'){

Chargement en cours ...

} @case ('success'){

Opération réussie !

} @case ('error'){

Une erreur est survenue.

} @default {

État inconnu

} }

4. @let (variable de template)

@let fullName = firstName + ' ' + lastName;

Nom complet : {{fullName}}

En majuscule : {{fullName.toUpperCase()}}
